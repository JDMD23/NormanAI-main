# Reviews

One file per audit of the user's repos, from `_template.md`, named
`<repo-name>-YYYY-MM.md` so repeat reviews show progress over time.

Rules:
- The verdict comes first and takes a position. Findings are ranked by impact and
  every one carries evidence + a concrete, effort-estimated recommendation.
- Reviews are judged against the user's stated goal and context, not abstract
  best practice. Right-size everything (brain/00, brain/06).
- Include "what's already good" and "what I'd not fix" — a review that flags
  everything prioritizes nothing.
