# Studies

One file per external repo studied, from `_template.md`. Studies are the evidence
trail for the brain: every principle added to `brain/` should trace back to at least
one study (or to the founding docs).

Rules:
- Clone external repos into the scratchpad, never into this repository.
- Study the architecture before the files; record what's *transferable*, not a tour.
- Every study ends with an explicit "brain updates made" section — even if empty.
- Re-studying a repo later gets a new dated section in the same file, not a new file.
